# v2.51 — Channel Brain

Channel Brain combines three evidence layers without loading another AI model:

1. Public YouTube Channel DNA — descriptive prior.
2. User-authorized YouTube Analytics — first-party performance evidence.
3. Local Learning DB — accumulated calibration from edits, feedback and outcomes.

Optional owned/reference edit analysis can be supplied as a fourth evidence layer for
actual pacing/cut/effect observations. The fusion produces soft targets and guardrails,
not a clone of another creator.

## Trust order

`owned reference edit evidence > owned Analytics > local repeated learning > public metadata`

No causal edit claim is generated from public metadata alone.

## CPU/RAM policy

Channel Brain is deterministic and model-free. It is executed before the Final Director
and adds no model process. The default architecture remains one real LLM process for final
synthesis.
