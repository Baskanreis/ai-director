# v2.67 Asset Browser ↔ Timeline

The Creative Library can now apply, insert, and vary marketplace assets directly on the timeline.

- `Klibe Uygula`: applies an asset non-destructively to the selected clip.
- `Timeline'a Ekle`: inserts an `asset://...` procedural reference on V1/A1.
- `Varyasyon Oluştur`: creates a deterministic recipe variation without copying media.

This keeps the 50K catalog metadata-first and preserves the single-Setup deployment contract.
