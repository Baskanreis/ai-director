# v2.59 — Shared Multimodal Scene Context

One timestamped SceneContext is built before specialist agents run. Vision, Speech,
Rhythm, Creative and semantic asset matching consume the same compact evidence.
This prevents duplicate media analysis and contradictory independent interpretations.

The built-in path is CPU-light and provider-neutral. An optional Vision/Speech provider
can enrich the same schema later; no additional model process is required by default.
