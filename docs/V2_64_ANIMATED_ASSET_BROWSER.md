# v2.64 Animated Asset Browser

## 50K discovery
- 50,000 metadata-first creative recipes remain the source of truth.
- Procedural micro-animation previews are generated on demand; no 50K video/GIF files are bundled.
- Preview profiles: glitch, neon, impact, cinematic, soft, beat, education, travel and clean.
- Existing preview cache is reused to keep scrolling responsive.

## Search
- Semantic aliases make common queries such as gamer, captions, broll, lut, reels and whoosh resolve to the relevant catalog vocabulary.
- Existing type, pack, favorites and drag/drop workflows remain intact.

## Single Setup
All runtime behavior remains inside the existing single Windows Setup distribution. No extra user installation is introduced.
