# v2.69 — Timeline Creative Asset Inspector

- Asset Browser stack entries can be edited directly from a selected timeline clip.
- Controls: intensity, speed, blend, duration, position and variation.
- Replace and Similar actions reuse the 50K discovery/visual-similarity engine.
- Changes remain recipe/metadata based; no media files are duplicated.
- One inspector session is one undo transaction; Cancel restores the entire session.
- Right-click a clip in Timeline → **Asset Inspector…**.
